Discogs

Discogs knows vinyl records far better than MusicBrainz. It is searched when MusicBrainz finds nothing, provided you have a (free) personal access token: create one on the Discogs Developers page (“Generate new token” button), then paste it here.

The token stays in this browser: it is never exported and is only sent to Discogs. It grants access to your Discogs account; if in doubt, regenerate it on the same page.
