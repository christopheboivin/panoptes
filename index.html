Discogs

Discogs connaît bien mieux les vinyles que MusicBrainz. Il est interrogé quand MusicBrainz ne trouve rien, à condition d'avoir un jeton personnel (gratuit) : crée-le sur la page Développeurs de Discogs (bouton « Generate new token »), puis colle-le ici.

Le jeton reste dans ce navigateur : il n'est jamais exporté et n'est envoyé qu'à Discogs. Il donne accès à ton compte Discogs ; en cas de doute, régénère-le sur la même page.
